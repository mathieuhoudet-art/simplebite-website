Simple Bite Açaí website preview

Open index.html in a browser to preview the website.

To publish for free:
1. Create a GitHub repository and upload index.html and the assets folder.
2. In Cloudflare Dashboard, go to Workers & Pages, create a Pages project, and connect the repository.
3. Set the build command to blank and output directory to / (root).
4. Preview on the free pages.dev address before connecting simplebiteacai.com.

Before launch: confirm hours, product-photo mappings, smoothie offerings, and pricing. Replace the menu navigation button with your Toast ordering URL when available.
